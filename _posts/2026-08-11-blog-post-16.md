### Server VS Client
- Client : 서비스를 요청(UI화면 구성하고 보여줌) -> 프론트엔드
- Server : 서비스를 제공(요청을 수신하고 처리, 데이터 관리) -> 백엔드

### 서버 클라이언드 구조
- 이 원리에 대해 이해를 해야지 어떤 개발자들이 어떤 파트에서 프로그래밍을 하는지를 알 수 있음

- 브라우저를 여는 우리의 개인 컴퓨터와 그 브라우저를 클라이언트라고함.

- URL을 입력하고 엔터를 누르는 순간 인터넷망을 통해 서버쪽에 데이터를 요청하게 됨. 

- 서버 같은 경우 클라이언트가 데이터를 요청하면 그 요청에 따라서 데이터를 보내주는 것

- 데이터를 요청하고 받는 원리이기 때문에 클라이언트 서버라는 이름이 붙여졌음.


### align items 속성
- stretch : 아이템을 늘려서 컨테이너의 교차축 가득 채움
- center : 교차축의 가운데로 정렬
- flex-start / start : 교차축의 시작 위치로 정렬
- flex-end / end : 교차축의 끝 위치로 정렬
- baseline : 내부 텍스트의 기준선에 맞춰 정렬
